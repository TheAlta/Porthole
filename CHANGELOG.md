## [1.0.0] - 2026-11-15

### Added
- Landing page with flight search, flight list and seat-type overview.
- Interactive seat map for a 156-seat Airbus A320 (BR 214, Barcelona → Paris CDG).
- Live 3D seat view built with Three.js — drag to look around from any seat.
- Flight timeline scrubber: takeoff, Pyrenees, sunset, Paris lights, touchdown.
- Window-shade control, in-cabin seat navigation (A–F, row forward/back).
- "No window" warning for window seats that sit behind a wall panel.
- Light and dark themes, smooth scrolling (Lenis) and scroll progress bar.
