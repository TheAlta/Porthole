# Security Policy

## Supported versions

| Version | Supported |
| ------- | --------- |
| 1.x     | ✅        |

## Reporting a vulnerability

Please **do not** open a public issue for security problems.
Use GitHub's [private vulnerability reporting](https://github.com/TheAlta/Porthole/security/advisories/new) instead.
You can expect an initial reply within a few days.
